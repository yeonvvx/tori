# UI Customization

## Color themes

Under **Settings → Appearance**, choose from built-in accent color themes or set a custom accent color.

## Background images

Set a custom background image (global or per-library-entry) under the same Appearance settings.

## Layout options

- Library view: grid density, card size, sort/filter defaults
- Home screen: reorder or hide sections (Continue Watching, Continue Reading, Schedule, etc)

## Discord Rich Presence

Toggle under **Settings → Discord** to show your current watch activity on Discord automatically. You can also hide specific info (like a repository/button link) from the presence card.
