# Manga

Tori includes a manga reader for local chapters and extension-sourced chapters, with a unified reading interface across both.

## Local manga

Add a manga library folder the same way as your anime library, under **Settings → Library**. Supported formats include folders of images and common archive formats (CBZ/ZIP).

## Extension-sourced manga

Install manga-source extensions from the [Extension Marketplace](Extensions.md). Once installed, matching series show available chapters directly from that source.

## Downloading chapters for offline reading

From a chapter's menu, choose **Download** to save it locally for offline access (see [Offline Mode](Offline-Mode.md)). Downloaded chapters are stored in Tori's manga downloads directory alongside your regular data.

## Reader settings

Customize reading direction (LTR/RTL), page layout (single/double page), and zoom/fit behavior under the reader's own settings panel.
