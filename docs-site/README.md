# Tori Documentation

Welcome to the Tori docs. Tori is a self-hosted media server with a web interface, a desktop app (**Tori Denshi**), and a companion mobile app (**Tori Tenji**) for browsing your library, tracking your AniList, and streaming or reading on the go.

> [!IMPORTANT]
> Tori does not provide, host, or distribute any media content. You are responsible for obtaining media through legal means and complying with your local laws.
