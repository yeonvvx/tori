# Auto Downloader

Automatically tracks and downloads new episodes for shows on your AniList as they release.

## Setting up

1. Go to **Settings → Auto Downloader**.
2. Enable it and choose a torrent-search extension/provider to use.
3. Set your default filters (resolution, release group preference, etc).

## Per-show rules

From an anime's page, you can override the global filters for that specific show — useful for shows where you want a specific release group or resolution.

## Advanced features

- **Prioritization** — rank preferred release groups so the downloader picks the best available match instead of the first one.
- **Scoring** — weight matches by combined criteria (resolution + group + seeders) rather than a single filter.
- **Delay** — wait a set time after a release is detected before downloading, to let better/more seeded releases show up first.
